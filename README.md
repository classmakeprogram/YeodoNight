# 프로젝트 개요

로봇 적과 싸우는 1인칭 액션 슈터. 스테이지마다 미션 3개(적 5명 처치 → 숨은 적 처치 → 헤드샷 3명)를
순서대로 클리어하면 다음 스테이지로 넘어가고, 스테이지 3부터 적 체력이 증가한다.
주무기 AK-47, 근접무기 카타나.

# 조작법 (현재 코드 기준)

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 이동 | 시점 |
| Shift (홀드) | 달리기 (스태미너 소모, 전진 중에만) |
| C | 웅크리기 토글 |
| Q | 구르기 (스태미너 소모) |
| Space | 점프 |
| 마우스 좌클릭 | AK 발사(홀드 연사) / 카타나 공격 |
| 마우스 우클릭 (홀드) | AK 정조준(줌) |
| R | 재장전 |
| 마우스 휠 / 1 / 2 | 무기 전환 |

# 스크립트 구조

| 파일 | 역할 |
|---|---|
| `PlayerController.cs` | 이동·시점·스태미너·AK·카타나·조준·사망·회복/탄약 획득·애니메이터 연동 |
| `RobotEnemyAI.cs` | 로봇 적 AI — 근접/원거리, NavMeshAgent 추격·공격 |
| `EnemyProjectile.cs` | 원거리 로봇 투사체 |
| `EnemyTarget.cs` | 적 체력·사망, 점수/미션/스포너 통지 |
| `Hitbox.cs` | 적 부위별 콜라이더 → 데미지 배수 후 EnemyTarget 전달 |
| `EnemySpawner.cs` | Mission / Waves 두 모드 스폰(싱글턴) |
| `MissionManager.cs` | 스테이지·미션 3종 순차 진행(싱글턴) |
| `ScoreManager.cs` | 점수·콤보·웨이브·생존시간 + 로컬 랭킹(싱글턴) |
| `GameManager.cs` | 타이틀→플레이→일시정지→결과→타이틀 흐름, 부스 방치 복귀(싱글턴) |
| `HUD.cs` | 히트마커·데미지 숫자·점수/콤보/웨이브·저체력 효과(싱글턴) |
| `LeaderboardUI.cs` | 결과 화면 이름 입력 + 순위 표시 |
